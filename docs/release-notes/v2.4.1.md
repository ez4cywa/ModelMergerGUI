# Cast Model Merger GUI v2.4.1

## 人物分档修复与瞄准镜玻璃修复

- **`_mat_info` 语义表支持**：导出目录带有 `_mat_info/<材质>.txt` 时，预览按源项目 `cast_spec.py` 同款规则交叉解析——语义 47 → 底色、48 → 打包 NOG 法线、4a → 遮罩，优先按贴图名匹配 cast 槽位，其次读取 `_images/<贴图名>.png`。MW/BO 人物资产（如 dallas 头部）的 NOG 法线与发片透明遮罩此前全部丢失，现在完整解析：皮肤/发片/眼睛/角膜/泪线/口腔按源项目 techset 与材质哈希规则精确分档，发片获得正确的透明剔除。
- **瞄准镜玻璃发黑修复**：玻璃材质此前回退到暗色调色板颜色且基础透明度过低，在暗色枪身内部呈纯黑。现在玻璃使用深蓝灰默认色调、更高的基础不透明度，并加强视角光泽与菲涅尔边缘增亮，暗色镜片呈现玻璃质感而非黑洞。
- `$black`/`$white`/`$identitypackednog` 哨兵按源项目语义处理；贴图名含 `lens`/`glass` 时识别为玻璃材质（命中全息瞄具镜片等哈希命名材质）。

Character profile classification now reads `_mat_info` semantic tables (semantic 47 = color, 48 = packed NOG, 4a = opacity) cross-validated against cast slots and `_images`, exactly like the shader project's cast_spec.py — resolving the NOG normals and hair opacity masks that named slots alone lose, and classifying skin/hair/eye/cornea/tearline/oral via the project's techset and material-hash rules. Optic glass no longer renders as a black hole: lenses use a dark blue-grey default tint, higher base opacity, and a stronger viewing-angle sheen with fresnel edge brightening.
