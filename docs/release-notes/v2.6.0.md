## CAST 装配台

Windows x64 免安装版。直接运行 **CastAssembly.exe**，或下载更小的 **CastModelMerger-win-x64.zip**，解压后运行其中的同名程序。

- 新名称和图标。EXE 文件、窗口和任务栏均使用新版图标。
- 左侧按组排列模型部件，右侧用标签来切换多个 3D 预览。输出设置在上方，当前组的运行日志在底栏。
- 保留多文件拖放和目标高亮。拖到预览区只预览，拖到模型组会追加部件，其他位置按批导入。
- 仅保留简体中文和 English，两种界面统一使用 MiSans 字体，并保留亮暗主题。旧版已移除的语言将改用 English，其他设置照常读取。

## Cast Assembly

Run **CastAssembly.exe** directly, or choose the smaller portable ZIP and extract it before running the EXE.

- New name and icon, including the Windows executable icon.
- Parts on the left, tabbed 3D previews on the right, output controls above and the active group's run log below.
- Batch drag-and-drop and light/dark themes remain available. Simplified Chinese and English use the same embedded MiSans font.
