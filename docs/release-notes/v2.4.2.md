# Cast Model Merger GUI v2.4.2

## 眼部与发片材质修复

- 不透明度遮罩（眼睛轮廓、泪线、发片）此前按 0.5 硬阈值二值剔除，alpha 渐变被压成锯齿条带，在眼睑周围出现粗黑条纹。现在不透明管线启用 **alpha-to-coverage**：遮罩值作为软覆盖率由 MSAA 抖动为平滑边缘，同时保留深度写入（发片卡片相互遮挡正确）。
- 角膜壳基础不透明度从 0.3 降至 0.1：正视时近乎完全透过（虹膜清晰可见），仅保留掠射角的玻璃光泽边缘，对齐源项目透射式角膜的表现。

Opacity masks (eye atlas, tearline, hair cards) were cut out with a hard 0.5 threshold, turning their alpha gradients into jagged dark bands around the eyelids. The opaque preview pipeline now uses alpha-to-coverage: the mask value becomes a soft, MSAA-dithered coverage while depth writes are preserved. The cornea shell's base opacity drops from 0.3 to 0.1 so the iris stays clearly visible through it, keeping only the grazing-angle glass sheen.
