# Cast Model Merger GUI v2.5.1

## 同代号输出自动区分

- 按武器代号推导的默认输出名（合并 `<代号>.cast`、弹匣装填 `<代号>_filled.cast`、手臂拼接 `<代号>_viewhands.cast`）现在会检查输出目录：已存在同代号文件时，把**原始部件文件名中有区分度的段**（代号之后、LOD 后缀之前，纯数字段跳过）前置于名称——先合并机匣 `att_sat_vm_ar_eagle_rec_LOD0` 得到 `eagle.cast`，再合并枪管 `att_sat_vm_ar_eagle_barl_LOD0` 会得到 `barl_eagle.cast`；弹匣装填依次得到 `anov94_filled.cast` → `mag_anov94_filled.cast`。
- 前缀名仍冲突时追加数字计数（`anov94_filled_1.cast`）；名称始终可手动修改；执行时若文件在此期间出现也会自动重推导，不再因命名冲突中断。
- 源项目：文件名无部件类型段时回退完整文件名 + 数字计数。

Code-derived default output names (merge `<code>.cast`, magazine fill `<code>_filled.cast`, arm assembly `<code>_viewhands.cast`) now check the output directory: when a same-code file already exists, the distinguishing segments of the original part stem (between the code and the LOD suffix, skipping pure-numeric segments) are prepended — `att_sat_vm_ar_eagle_rec_LOD0` then `att_sat_vm_ar_eagle_barl_LOD0` produce `eagle.cast` and `barl_eagle.cast`; magazine fills chain `anov94_filled.cast` → `mag_anov94_filled.cast`. A numeric counter resolves remaining collisions, names stay editable, and execution re-derives automatically instead of failing.
