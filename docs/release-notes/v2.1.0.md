## v2.1.0 中文说明

这一版本集中提升大型模型预览、多模型组操作反馈、发布可靠性和 CAST 输入稳健性。

- 模型预览改用 WGPU 顶点缓冲和深度缓冲；旋转、缩放、明暗与遮挡由 GPU 完成，显示上限提高到 250,000 个三角面。
- 文件导入和任务启动错误显示在对应模型组内；拖入文件时，目标组会同时显示高亮边框和明确文字。
- 无控制台的启动失败现在会写入 `%LocalAppData%\CastModelMerger\logs`，并显示可打开日志目录的中英双语恢复提示。
- CAST 解码增加可配置的节点、属性、数值与文本资源预算，并加入定期模糊测试。
- 新增 Windows CI、Cargo 版本与 Git 标签一致性检查、干净源码发布检查，以及 ZIP 和 SHA-256 双资产发布。
- GUI 的 GPU 预览、消息本地化和通知路由已拆成独立模块；MiSans 资源归入 Rust GUI，迁移期 worker 不再参与默认 workspace。

下载 `CastModelMerger-win-x64.zip` 后完整解压，直接运行 `CastModelMerger.exe`。不需要安装 .NET、Rust 或其他额外运行环境；若窗口无法创建，请先更新显卡驱动。

## v2.1.0 English notes

This release improves large-model preview performance, feedback across multiple groups, release integrity, and resilience against malformed Cast input.

- Model previews now use WGPU vertex and depth buffers. Rotation, zoom, lighting, and occlusion run on the GPU, with a display limit of 250,000 triangles.
- File-selection and scheduling errors stay inside the affected group. A drag target uses both a highlighted border and explicit text.
- Console-less startup failures are logged under `%LocalAppData%\CastModelMerger\logs` and shown in a bilingual recovery dialog that can open the log directory.
- The Cast decoder has configurable aggregate budgets for nodes, properties, values, and text, plus scheduled fuzz testing.
- Windows CI now verifies formatting, warning-free Clippy, tests, the native release build, and Windows icon resources. Release tags must match Cargo versions, rebuild from a clean tagged tree, and publish both ZIP and SHA-256 assets.
- GPU rendering, localized semantic messages, and notice routing are isolated modules. MiSans belongs to the Rust GUI asset tree and the migration worker is outside the default workspace.

Extract `CastModelMerger-win-x64.zip` completely and run `CastModelMerger.exe`. No .NET, Rust, or other additional runtime is required. Update the graphics driver first if the window cannot be created.
