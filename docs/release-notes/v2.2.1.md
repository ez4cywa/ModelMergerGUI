# Cast Model Merger GUI v2.2.1

## 2026-09-08 装填兼容性、备用弹匣与窗口更新（版本号不变）

- 修复输出文件系统不支持硬链接时，装填保存出现“函数不正确”的问题；仍不会覆盖已有文件。
- 支持选择空备用弹匣，复制主弹匣的子弹布局，并将新增子弹绑定到对应备用弹匣骨骼。
- “关于”新增 GitHub 更新检查，可手动检查或开启启动检查，默认关闭；不会自动下载安装。
- 主窗口采用 macOS 风格红黄绿按钮和居中标题，支持关闭、最小化、最大化、拖动和边缘缩放。
- 修复关于窗口展开内容后的滚动交互，完成 84 项自动测试及明暗界面检查。GitHub 匿名接口受限流时会提示检查失败，可稍后重试或手动下载。

### Same-version multilingual layout refresh

Toolbars now adapt to translated text widths. Fixes group-chevron overlap, broken Russian preview labels, Browse-button sizing and settings-pane alignment. Magazine filling keeps its actions visible while content scrolls; preview commands wrap in related pairs. English, French, Russian and Spanish layouts were inspected, with automated checks covering all five languages. Version remains **2.2.1**; download the refreshed ZIP to receive these fixes.

预览窗口统一采用主界面的字体、圆角工具栏、按钮和明暗配色；模型采用随主题变化的中性灰着色，长模型名截断显示，避免挤压窗口。

在 v2.2.0 弹匣装填与 macOS 风格界面的基础上，新增“其他子弹骨骼（按需勾选）”。`j_ammo_17` 等不属于弹匣子树的编号子弹骨骼也可以单独装填，或与弹匣一起装填，默认不勾选。已占用的位置仍自动跳过。

使用：点击“弹匣装填”，选择武器和子弹模型，在弹匣组下方勾选需要的其他子弹骨骼，另存为新的 CAST 文件。也可以取消所有弹匣组，仅装填这些单独位置。

## English

The preview window shares the main app's typography, rounded toolbar, controls and light/dark palette, with theme-aware neutral model shading and truncated long model names.

Adds optional individual ammunition bones outside magazine subtrees, such as `j_ammo_17`. Select them under **Other ammunition bones (optional)**, either alone or together with magazines. They are unchecked by default; occupied slots are still skipped.

Includes v2.2.0's magazine filling, macOS-inspired UI, compact inputs and five interface languages. Extract the ZIP and run `CastModelMerger.exe`; no .NET or Rust installation required. Reference model files are not included.
