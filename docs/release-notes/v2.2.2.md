# Cast Model Merger GUI v2.2.2

## 2026-09-14 亮暗切换与弹匣界面精简（版本号不变）

- 菜单栏右侧新增醒目的亮／暗主题切换按钮，自动保存选择；主界面和预览同步切换，切换语言不会重置主题。
- 弹匣名称只显示一次，装填目标与复制来源合并在同一行，移除重复的来源下拉框，两种选择仍互不干扰。
- 骨骼明细改为悬停查看，只在需要时拼接和排版，减少常规界面的重复工作。
- 支持五种语言和明暗主题，保留既有装填与复制逻辑。

Added a prominent, persistent light/dark toggle at the right of the menu bar. Simplified magazine selection into one row per magazine with independent fill-target and copy-source controls. Bone details are generated only when hovered. Version remains **2.2.2**; download the refreshed ZIP.

## 2026-09-14 专用预览区、分批导入与崩溃日志（版本号不变）

- 新增固定的模型预览区，支持拖入或点击多选 CAST 文件，分别打开独立预览。
- 其他区域用于导入部件：拖到指定模型组会追加到该组；拖到普通区域时，每批独立成组，优先复用空组，无需先合并上一批。
- 三类拖放目标都有高亮和对应提示，适配五种语言及明暗主题。
- 修复 Windows 拖放缺少普通鼠标移动事件时，区域命中失效、文件无响应的问题；拖放期间读取实际鼠标位置并换算窗口缩放。
- 增强本地诊断日志：记录版本、进程、显卡、预览路径和加载/关闭事件；Rust panic 记录堆栈，Windows 原生异常尽可能记录异常码及地址。错误提示可打开日志目录。
- 此次增加排查预览崩溃所需的证据收集，不代表此前未复现的预览崩溃已修复。

Added a dedicated multi-file preview drop area and separate import batches outside existing groups. Drag targets now highlight with localized hints. Fixed Windows file-drop routing when ordinary cursor events are missing. Added local panic backtraces, native exception details, GPU information and preview lifecycle logs. The previously unconfirmed preview crash still requires reproduction and logs. Version remains **2.2.2**; download the refreshed ZIP.

## 2026-09-11 拖入 CAST 即可预览（版本号不变）

- 将 CAST 文件拖到主工作区空白处即可打开独立预览，支持同时拖入多个文件，不改变合并组。
- 拖到模型组内仍按原逻辑添加部件；空白处拖入预览提供高亮和五种语言提示，并适配明暗主题。
- 忽略非 CAST 文件，无法加载的 CAST 文件显示正常的预览错误提示。

Drop one or more CAST files onto empty workspace space to open standalone previews without changing merge groups. Dropping onto a group still adds parts. Includes theme-aware highlighting and localized hints. Version remains **2.2.2**; download the refreshed ZIP.

## 2026-09-09 全局预览布局更新（版本号不变）

- 独立预览、部件预览和合并结果预览统一采用全窗口布局：顶部名称、中央模型、左下视角工具、底部“视图 / 模型信息”。
- 保持现有 macOS 风格、明暗主题和五种语言，并将红黄绿窗口控制应用于预览窗口。
- 新增可开关的透视地面网格，与模型共用相机和深度遮挡；支持旋转、缩放、复位，以及 G 键切换网格。
- 模型信息页显示原始网格、顶点、三角形、实际显示三角形和尺寸；保留后台加载、错误提示和大模型抽样说明，不改写源文件。

All CAST previews now share a full-window layout with a compact name row, lower-left camera tools, and **Viewport / Model info** tabs. Added a toggleable perspective ground grid with depth occlusion, macOS-style preview window controls, and geometry details. Version remains **2.2.2**; download the refreshed ZIP.

## 独立 CAST 预览更新（版本号不变）

- 新增“文件 → 打开模型预览…”和 Ctrl+O 快捷键，直接选择 CAST 文件并打开独立 3D 预览窗口，无需添加模型组部件。
- 预览沿用旋转、缩放、重置视角及后台加载；不会修改源文件或合并组，取消文件选择不会产生空预览窗口。
- 菜单入口和文件选择窗口支持五种语言，版本仍为 **2.2.2**，请下载刷新后的 ZIP。

Added **File → Open model preview…** and **Ctrl+O** for standalone CAST viewing. Opens the existing 3D preview without adding files to a merge group. Canceling the picker leaves the workspace unchanged. Version remains **2.2.2**; download the refreshed ZIP.

## macOS 风格菜单栏

- 用紧凑的“文件 / 设置 / 帮助”菜单栏替换原来的顶部按钮区，移除重复的应用标题和文字介绍，为模型工作区留出更多空间。

- 保留 macOS 风格红黄绿窗口按钮，适配五种语言、明暗主题以及默认和最小窗口尺寸。
- 包含 v2.2.1 的装填保存兼容性修复、备用弹匣布局复制和默认关闭的 GitHub 更新检查。

## English

Replaced the previous header and command buttons with a compact macOS-inspired **File / Settings / Help** menu bar. Removed the repeated application heading and introduction to give models more workspace.

Create groups under **File**; choose a language or save/restore settings under **Settings**; open version information and update checks under **Help → About**. Existing shortcuts remain available with platform-specific hints. Menus support keyboard opening and Escape dismissal, all five languages, both themes, and minimum window dimensions.

Includes the v2.2.1 magazine-save compatibility fix, spare-magazine layout replication, and opt-in GitHub release checks (off by default).
