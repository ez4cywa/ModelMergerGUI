# Cast Model Merger GUI v2.2.2

## 独立 CAST 预览更新（版本号不变）

- 新增“文件 → 打开模型预览…”和 Ctrl+O 快捷键，直接选择 CAST 文件并打开独立 3D 预览窗口，无需添加模型组部件。
- 预览沿用旋转、缩放、重置视角及后台加载；不会修改源文件或合并组，取消文件选择不会产生空预览窗口。
- 菜单入口和文件选择窗口支持五种语言，版本仍为 **2.2.2**，请下载刷新后的 ZIP。

Added **File → Open model preview…** and **Ctrl+O** for standalone CAST viewing. Opens the existing 3D preview without adding files to a merge group. Canceling the picker leaves the workspace unchanged. Version remains **2.2.2**; download the refreshed ZIP.

## macOS 风格菜单栏

- 用紧凑的“文件 / 设置 / 帮助”菜单栏替换原来的顶部按钮区，移除重复的应用标题和文字介绍，为模型工作区留出更多空间。
- “文件”中可新建模型组；“设置”中可切换语言、保存设置或恢复默认；“帮助 → 关于”可查看版本、检查更新和访问项目链接。
- 保留 Ctrl+N、Ctrl+S 等现有快捷键，并在菜单项旁显示对应操作系统的快捷键提示。支持键盘打开菜单和 Esc 关闭。
- 保留 macOS 风格红黄绿窗口按钮，适配五种语言、明暗主题以及默认和最小窗口尺寸。
- 包含 v2.2.1 的装填保存兼容性修复、备用弹匣布局复制和默认关闭的 GitHub 更新检查。

## English

Replaced the previous header and command buttons with a compact macOS-inspired **File / Settings / Help** menu bar. Removed the repeated application heading and introduction to give models more workspace.

Create groups under **File**; choose a language or save/restore settings under **Settings**; open version information and update checks under **Help → About**. Existing shortcuts remain available with platform-specific hints. Menus support keyboard opening and Escape dismissal, all five languages, both themes, and minimum window dimensions.

Includes the v2.2.1 magazine-save compatibility fix, spare-magazine layout replication, and opt-in GitHub release checks (off by default).
