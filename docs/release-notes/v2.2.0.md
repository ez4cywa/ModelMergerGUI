# Cast Model Merger GUI v2.2.0

- 新增“弹匣装填”：识别弹匣子树中的子弹骨骼，按数量复制子弹模型，逐槽定位、旋转并刚性绑定。默认选择第一弹匣，可勾选其他组。
- 显示已占用和排除骨骼；自动跳过已占用目标；另存新 CAST，支持后台进度、取消和结果预览。
- 保留原模型节点和材质数据；不附带参考模型文件。
- macOS 风格界面、系统明暗主题、36px 输入框、紧凑进度条及键盘快捷键。

使用：模型组部件区 → 弹匣装填 → 选择武器与子弹 CAST → 勾选弹匣 → 选择新输出文件 → 装填 → 预览。

子弹源目前要求单个 `tag_ammo` 骨骼，骨骼必须为单位缩放。每组识别实际模型骨骼数，不推测武器容量。备用动画弹匣可能在参考姿态下重叠。

## English

- Adds **Fill magazine**: discover magazine ammunition bones, instance and orient a cartridge model at each empty slot, and bind each instance to its target bone.
- Select magazine groups, inspect occupied/excluded slots, save a new CAST, cancel background work, and preview the result.
- Preserves original model nodes and material data. Reference model assets are not distributed.
- Adds a macOS-inspired interface, system light/dark themes, compact input controls, progress bars and shortcuts.

Usage: group parts area → Fill magazine → choose weapon and ammunition CAST → select magazine groups → choose a new output → fill → preview.

Requires a single `tag_ammo` source bone and unit-scale skeletons. Counts come from model bones. Alternate animation magazines may overlap in the reference pose.

Extract `CastModelMerger-win-x64.zip` and run `CastModelMerger.exe`. No .NET or Rust installation required.
