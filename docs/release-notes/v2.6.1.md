## CAST 装配台：精简 EXE

MiSans Medium 现在以无损压缩形式内嵌，程序启动时还原到内存。保留完整字库，无需额外安装字体或字体文件。

现有中英文界面、亮暗主题、拖放、模型合并、3D 预览和弹匣装填保持不变。下载 **CastAssembly.exe** 直接运行，或选择 Windows x64 ZIP 版，解压后运行。

## Cast Assembly: smaller EXE

The full MiSans Medium font is now embedded losslessly and restored in memory once per launch. No font installation or external files are needed. The interface and existing model tools are unchanged.
