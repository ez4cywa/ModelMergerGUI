# Cast Model Merger GUI v2.4.3

## 眼球被遮罩误伤修复

- 数据核查发现：眼睛材质的语义 4a 贴图是平滑渐变（阴影类数据），并非发片/泪线那样的剪影遮罩——把它当覆盖率抖动会抹掉约七成眼球，看起来像闭眼。现在只有源项目 `profiles.json` 中声明 `requires: ["opacity"]` 的**发片**与**泪线**应用 4a 遮罩，眼球恢复完全不透明渲染，与源项目一致。

The eye material's semantic-4a texture turned out to be a smooth gradient (shadow data), not the bimodal coverage silhouette that hair cards and the tearline carry — dithering the eyeball with it erased most of the eye. Only the profiles that declare `requires: ["opacity"]` in the shader project (hair_card, tearline) now apply the 4a mask; the eyeball renders fully opaque again, matching the source project.

- 发布包精简：ZIP 现在只包含主程序 `CastModelMerger.exe` 与中英文使用指南（`docs/user-guide.zh-CN.md`、`docs/user-guide.en.md`），不再附带 README、截图与第三方声明。

The release ZIP now ships only the executable and the bilingual user guides.
