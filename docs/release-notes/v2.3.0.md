# Cast Model Merger GUI v2.3.0

## 可选的带材质模型预览

- 预览窗口工具栏新增棋盘格“材质”开关（**默认关闭**），开启后模型按材质贴图渲染：albedo 颜色贴图（sRGB）+ 打包 NOG 法线（G/A 联合编码还原切线空间法线，R 通道作为光泽候选），并支持遮罩透明剔除。
- NOG 解码与槽位角色表源自 [ez4cywa-cod-blender-shaders](https://github.com/ez4cywa/ez4cywa-cod-blender-shaders) 的 COD 材质逆向研究：`albedo/diffuse/basecolor` → 颜色，`normal/nog` → NOG，`opacity` → 遮罩。
- 贴图按 cast 文件中的路径在后台线程解码，不阻塞界面；底部状态栏显示加载进度，文件缺失时逐材质回退纯色并提示。
- 合并输出的 `.cast` 现在**保留输入部件的贴图路径**（此前会写空），合并后的模型同样可以带材质预览；同名但贴图不同的材质不再被错误合并。
- 支持五种语言与明暗主题；材质预览同样只读，不修改源文件与合并结果。

Optional material preview lands in the model preview window. A checkerboard **Materials** toggle (off by default) switches the GPU shader from flat colors to textured rendering with sRGB albedo and COD-style packed NOG normal decoding, following the research in [ez4cywa-cod-blender-shaders](https://github.com/ez4cywa/ez4cywa-cod-blender-shaders). Textures decode on background threads from the paths stored in the cast file, with per-material flat fallback and a status indicator. Merged `.cast` outputs now keep material texture paths, so merged models preview with materials too; same-name materials with different textures are no longer collapsed. Available in all five languages and both themes; still fully read-only.
