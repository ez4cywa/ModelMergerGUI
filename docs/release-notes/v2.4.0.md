# Cast Model Merger GUI v2.4.0

## 材质预览分档渲染（对齐源 shader 项目的 profile 体系）

- 材质预览现在按材质名与文件名自动分类，并套用 [ez4cywa-cod-blender-shaders](https://github.com/ez4cywa/ez4cywa-cod-blender-shaders) `profiles.json` 的控制参数渲染，人物、武器、玻璃在预览中有明显不同的观感。
- **武器 weapon**：金属度 1.0，albedo Alpha 作为金属候选，金属区域呈反射式高光。
- **玻璃 glass**：薄壁透射（IOR 1.46），菲涅尔边缘高光，半透明叠加绘制；**角膜 cornea** 同样透射并断开底色（白）。
- **人物 character**：皮肤（SSS 0.22 包裹漫反射 + 轻清漆）、发片（不透明度剔除 + Sheen 边缘光 + 法线强度 0.4）、眼睛（Coat 0.8 强清漆）、泪线、口腔、布料（Sheen 0.15）各自套用研究参数。
- 透射类材质（玻璃/角膜）在不透明几何之后单独以深度测试 + Alpha 混合绘制，可以正确透出其后方的模型。
- 分类规则首个命中生效：武器名称/资产路径规则沿用源项目正则；研究项目基于 `_mat_info` techset 的规则在通用 cast 上不可用，人物子档改用通用名称提示（`skin`/`hair`/`eye`/`cornea`/`tear`/`oral`/`cloth`）。
- 仍然默认关闭、完全只读；支持五种语言与明暗主题。

Material preview now classifies every material by name and file stem and renders it with the control values from the shader project's `profiles.json`, so weapons (metalness 1.0 with alpha metal candidates), characters (skin SSS wrap, hair sheen cards, glossy eyes, transmissive cornea) and optic glass (thin-wall IOR 1.46 transmission with fresnel highlights, alpha-blended over opaque geometry) all look distinctly different. Rules are first-match-wins; techset rules that need `_mat_info` tables fall back to generic name hints for character sub-profiles. Still off by default and fully read-only.
