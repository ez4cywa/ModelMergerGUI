## v2.0.1 中文说明

这是 Cast Model Merger GUI 的 Windows 图标修复版本。

- 将多尺寸应用图标正式嵌入 `CastModelMerger.exe` 的 Windows 资源中。
- 修复资源管理器中 EXE 不显示软件图标的问题。
- 修复任务栏、固定快捷方式和 Windows Shell 回退路径可能显示空白图标的问题。
- 发布流程新增自动图标回归检查，同时验证 EXE 图标资源与运行窗口图标。

下载并完整解压 `CastModelMerger-win-x64.zip`，然后运行 `CastModelMerger.exe`。不需要安装 .NET、Rust 或其他额外运行环境。

## v2.0.1 English notes

This patch fixes the Windows application icon for Cast Model Merger GUI.

- Embeds the multi-size application icon in the Windows resources of `CastModelMerger.exe`.
- Fixes the missing executable icon in File Explorer.
- Fixes blank icon fallbacks in the taskbar, pinned shortcuts, and Windows Shell.
- Adds an automated release regression check for both executable resources and the running window icon.

Extract `CastModelMerger-win-x64.zip` completely and run `CastModelMerger.exe`. No .NET, Rust, or other additional runtime is required.
