# Cast Model Merger GUI v2.5.3

## 稳定性与工程流程改进

- 及时回收已结束任务的调度记录，减少反复合并时的内存累积；保留界面中的结果、进度、日志和覆盖确认。
- 设置保存与模型输出只清理本次成功创建的临时文件，避免同名临时文件冲突时改写或误删已有文件；覆盖合并、弹匣装填和手臂拼接流程。
- 未启用覆盖时，保留合并过程中由其他程序创建的同名输出文件，并进入已有的覆盖确认流程。
- 本地、CI 和默认发布共用 `scripts/Test-RustWorkspace.ps1`，统一检查格式、Clippy、工作区测试及原生浏览器／剪贴板集成；依赖检查和发布构建使用已提交的 `Cargo.lock`。
- 验证：132 项测试通过，2 项手动探针跳过；格式、Clippy、原生集成检查及 13 项脚本失败流程验证通过。

Finished scheduler records are reclaimed while the UI retains results, progress, logs and overwrite confirmation. Settings saves and model operations clean up only temporary files they successfully created. Merging without overwrite enabled preserves an output created by another process during the operation and uses the existing overwrite-confirmation flow. Local checks, CI and default release builds now share one verification script and use the committed dependency lockfile. Verification passed 132 tests, with two manual probes skipped, plus formatting, Clippy, native integration checks and 13 script failure-path checks.
