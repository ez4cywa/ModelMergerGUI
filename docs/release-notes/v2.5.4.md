# Cast Model Merger GUI v2.5.4

本版修复已复现的普通 CAST 合并数据保真问题。用户反馈的 Maya“平滑组混乱”尚未复现，不能据此声称已彻底修复该现象。原始模型不会被修改。

## CAST 合并保真修复

- 保留全部 UV 层及其声明，不再只写出第一套 UV；保留多层打包整数或浮点顶点颜色，兼容旧版 `vc` 输入，不再将原始颜色替换为白色。
- 保留网格蒙皮方式 `sm` 及根模型的 up-axis 元数据；`sm` 是蒙皮方式，不是平滑组。拒绝直接合并已声明不同 up-axis 的模型，避免误标坐标系。
- 写出纹理引用时将相对路径锚定到各自的源 CAST 目录，防止更换输出目录后失链；保留空路径与绝对路径。纹理不会被复制，源纹理仍须可访问。
- 同名材质引用不同源目录中的同名纹理时保持独立，避免后一个部件错误引用前一个部件的贴图。
- 保留原始法线和拓扑，不增加顶点焊接、自动平滑或法线重算。

## 验证与已知限制

- 新增 14 项着色保真、旧版兼容和非法输入回归测试；全工作区 146 项测试通过，2 项手动探针按约定跳过；格式、Clippy 及原生集成检查通过。
- 使用用户提供的机匣与弹匣样本在 Maya 2027 中实测：13 个网格的逐面顶点法线差为零，硬软边和法线锁定状态一致；第二套 UV、当前 UV 集、顶点颜色和 Z-up 得以保留，输出的 168 个纹理引用均可访问。
- 本次数据丢失修复针对普通合并路径；不能将其等同于所有装填、手臂拼接或 Maya 插件流程中的平滑问题均已解决。若仍有异常，请附异常输出 CAST、操作步骤、Maya／CAST 插件版本及截图反馈。

This release fixes verified fidelity loss in ordinary CAST merging: multiple UV/color layers, skinning method, root up-axis, source-relative texture references, and same-name material isolation. It preserves authored normals and topology without welding or recalculating normals. Texture files are referenced in their original locations, not copied. Conflicting declared up axes are rejected rather than silently relabeled. Maya 2027 checks on the supplied receiver/magazine samples preserved all 13 meshes' face-vertex normals, hard/soft edges and locked-normal state; all 168 texture references resolve. The originally reported Maya smoothing anomaly has not been reproduced and is not claimed to be fully resolved.
