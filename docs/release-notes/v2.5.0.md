# Cast Model Merger GUI v2.5.0

## 手臂武器拼接（可选功能，默认关闭）

- 新增"手臂武器拼接"工具：把武器模型拼接到手臂骨架，生成完整的第一人称 viewmodel。在菜单 **设置 → 手臂武器拼接** 勾选开启（默认关闭），每组部件区出现工具按钮。
- 拼接方式：武器根骨骼（如 `j_gun`）以**零位移**挂接为手臂 `tag_weapon`（自动探测，可下拉改选）的子骨骼；武器骨骼层级与蒙皮权重完整保留，与手臂骨骼重名时自动加 `_wpn` 后缀；武器贴图路径改写为绝对路径。输出为全新 CAST，不修改输入文件。
- 输出命名统一按**武器代号**（文件名中部件类型段前一段）推导：
  - 合并输出默认 `<代号>.cast`（如 `att_sat_vm_ar_eagle_rec_LOD0` → `eagle.cast`）
  - 弹匣装填默认 `<代号>_filled.cast`
  - 手臂武器拼接默认 `<代号>_viewhands.cast`
  - 找不到部件类型段时回退完整文件名，名称始终可手动修改。

New opt-in **Arm + weapon assembly** tool (off by default; enable in Settings): the weapon's root bone splices into the arms skeleton as a zero-offset child of `tag_weapon` (auto-detected, overridable), preserving the weapon's bone hierarchy and skin weights with collision-suffixed names and absolute texture paths. Output naming is unified around the weapon code extracted from the file stem: merges default to `<code>.cast`, magazine fills to `<code>_filled.cast`, and arm assembly to `<code>_viewhands.cast` — always editable.
